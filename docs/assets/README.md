# Fern logo

The fern frond and unfurling tip identify the language without relying on an
emoji or text inside the image. Both transparent PNGs are intended for small
repository headers and avatars:

- `fern-logo.png`: forest-green mark for light backgrounds.
- `fern-logo-light.png`: light sage mark for dark backgrounds.

The root README selects the appropriate variant using `prefers-color-scheme`.
Keep the mark's proportions and surrounding space; provide the name “Fern” as
accessible text when the logo identifies the project.

Created with the built-in image-generation tool on 2026-09-06. These are raster
assets, not editable vectors. The original generated PNGs and their transparency
are preserved. Like the rest of this repository, they use the MIT license.

## Generation prompt

Use case: logo-brand. Create an original, polished logo mark for Fern, an approachable statically typed functional programming language. Asset: a square repository avatar and README logo, no text. Design a single compact fern frond from a clean gently curving central stem and three paired, broad geometric leaflets with a small unfurling tip; the silhouette should subtly suggest a lowercase f without becoming a literal letter. The feel is calm, precise, friendly and botanical, with the clarity of a well-crafted programming tool. Flat deep forest green mark on a uniform warm ivory background. Strong simple silhouette, crisp clean edges, disciplined negative space, optically centered with generous 20% margin, readable at 48 pixels. Square 1024x1024 composition. No lettering, no wordmark, no emoji appearance, no veins or tiny details, no gradients, no shadows, no 3D, no texture, no mockup, no border, no watermark. Only the finished logo mark on its clean background.

## Dark-background variant prompt

Use case: identity-preserve. This is the finished Fern programming-language logo. Create its dark-background variant. Change only the green ink of the fern mark to a uniform light sage green, approximately #C5DFA0. Preserve the exact silhouette, spiral tip, every leaf, stem, size, placement, spacing and square canvas. Preserve the actual transparent background and alpha, with clean antialiased edges. Do not add a background, text, border, texture, gradient, glow, shadow or any new element. It must read clearly at 48px on charcoal #0D1117.
